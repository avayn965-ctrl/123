Неофициальное обновление RefreshAncient 1.4.3 (автор исходного мода — Sparking3985) для **Slay the Spire 2 v0.111.0** от 14 августа 2026 года, commit `41cef1ea`.

## Что изменилось

- **«Все варианты»** рядом с обновлением наград открывает окно с карточками наград текущего Древнего: оригинальные иконки и контуры, игровой фон и шрифты, золотые заголовки, цветные описания и отметки «На экране», «Уже показан», «Ещё доступен», «Недоступен».
- **«Все Древние»** рядом со сменой Древнего показывает пул текущего события с учётом акта и разблокировок, включая уже встреченных Древних. У каждого названия — миниатюра с контуром из верхней панели игры, рядом со счётчиком этажей.
- Оба окна служат **только для просмотра**: выбор из списка невозможен, золото и RNG не расходуются. Длинные списки прокручиваются; окно закрывается кнопкой, крестиком или Escape. Просмотр доступен и после исчерпания пула.
- **«Сменить Древнего»** исключает начального Древнего и все успешные замены в этой комнате. После исчерпания пула кнопка блокируется с предупреждением **«Новых Древних нет»**; золото не списывается. Неудачная замена не расходует кандидата.
- **Refresh Options** исключает все варианты, уже показанные у текущего Древнего, включая начальный экран. Повторы не возвращаются на третьем, четвёртом и последующих перебросах.
- Если новых вариантов осталось меньше размера исходного набора, предлагается только остаток.
- При исчерпании кнопка блокируется с надписью **«Новых вариантов нет»** и объясняющей подсказкой. Заблокированное нажатие не отправляет запрос и не списывает золото.
- История отдельная для каждого игрока и экземпляра события. Сохраняются проверки доступности наград стандартных Древних: карты/зачарования, питомец, разблокированные персонажи и другие условия.
- Русские кнопки, предупреждения, подсказки, подписи и описания настроек. Язык определяется настройками игры. Английский и китайский сохранены.
- Сохранены исправление **Refresh Ancient** из compat.1 и функции compat.2.

Варианты определяются по `TextKey`, используемому сетевым протоколом. Варианты одной награды с одинаковым ключом считаются одним выбором. Повторные наборы выбираются из общего доступного пула Древнего, без ограничения исходными группами по слотам.

Истории хранятся **в памяти**: награды — для экземпляра события, Древние — для игрока и комнаты текущего забега. После перезапуска игры или загрузки сохранения учёт начинается заново с текущего экрана. Варианты, показанные старой версией мода до обновления, восстановить нельзя. Смена Древнего начинает новую историю наград, сохраняя историю Древних комнаты. В следующей комнате Древние снова доступны. Служебные значения настроек `Standard/Easy/Test/Custom` и `Enabled/Disabled` сохранены для совместимости.

## Установка

1. Полностью закройте игру и сохраните прежние `RefreshAncient.dll`, `RefreshAncient.json` и `RefreshAncient.pck` вне папки `mods`.
2. Скопируйте три файла из ZIP в папку игры `mods` с заменой; не оставляйте вторую копию мода в подпапках.
3. Запустите игру заново. Версия манифеста должна быть **1.4.3-compat.4**.

Для мультиплеера установите одинаковую версию у всех участников. BaseLib остаётся необходимой зависимостью. Для отката верните сохранённые файлы предыдущей версии.

Проверьте обновление в тестовом забеге. При ошибке сохраните `godot.log` сразу после нажатия.

## Проверки

20 сценариев проходят как на исходном помощнике, так и на его коде, встроенном в итоговую DLL: перебросы наград и Древних без повторов до исчерпания, неудачные замены, последний неполный набор, доступность наград, независимость игроков/комнат/забегов, совпадение хоста и клиента на стенде, защита от повторных результатов, статусы каталогов и отсутствие расхода RNG при просмотре.

25 проверок интерфейса проходят на настоящем **Godot 4.5.1 Mono** также для исходного и встроенного кода: создание и размещение кнопок, карточки с игровым фоном, иконки реликвий и Древних с контурами, сохранение цветных выделений, перенос длинных описаний, отсутствие игровых обработчиков у копий, отдельное модальное окно, прокрутка, закрытие и Escape, блокировка платных действий при просмотре, отсутствие дубликатов и доступность списка при исчерпании пула.

Статические проверки подтверждают подключение путей одиночной игры, хоста и приёма результатов; сохранение исправлений compat.1; наличие API в предоставленной DLL игры и отсутствие дополнительной зависимости на помощник.

**Настоящий запуск игры и сетевой сеанс compat.4 здесь не проверены.** Тесты Godot используют подставные типы игры. Условия наград Древних из сторонних модов отдельно не проверены.

## Сборка из исходников

Нужны .NET SDK 9, Python 3, исходный ZIP RefreshAncient 1.4.3 и ваша `sts2.dll` v0.111.0:

```sh
python tools/build_release.py --game-dll /path/to/sts2.dll --original-mod /path/to/original-mod.zip
```

Для включения проверок интерфейса добавьте `--godot /path/to/Godot_v4.5.1-stable_mono_linux.x86_64` (Godot 4.5.1 Mono).

Без игры можно запустить тесты новой логики:

```sh
dotnet run --project tests/FeatureTests.csproj
```

Подробности — [`src/README.txt`](src/README.txt). Сама DLL игры в репозиторий не включена. Тестовая сборка с именем `sts2.dll` содержит только подставные типы; её нельзя помещать в папку игры.

Предыдущие архивы compat.1, compat.2 и compat.3 оставлены в [`dist`](dist); исходный отчёт — [`VALIDATION.txt`](VALIDATION.txt).
