Неофициальное исправление совместимости RefreshAncient 1.4.3 (автор исходного мода — Sparking3985) с игрой v0.111.0 от 14 августа 2026 года, commit `41cef1ea`.

## Установка

1. Полностью закройте игру.
2. Сохраните копии старых `RefreshAncient.dll`, `RefreshAncient.json` и `RefreshAncient.pck` вне папки `mods`.
3. Распакуйте эти три файла из скачанного ZIP в папку игры `mods` с заменой.
4. Запустите игру заново. Версия мода в манифесте — `1.4.3-compat.1`.

Для мультиплеера у всех участников должны быть одинаковые файлы патча. BaseLib остаётся необходимой зависимостью; в предоставленном журнале установлен BaseLib 3.4.7.

Проверьте кнопку **Refresh Ancient** в тестовом забеге после окончания диалога Древнего. При повторной ошибке сохраните `godot.log` сразу после нажатия. Для отката закройте игру и верните три исходных файла.

## Исправления

- Вызов `EventModel.BeginEvent` передаёт дополнительный `EventCombatSynchronizer` из текущего `EventSynchronizer`.
- Поиск конструктора `EventSynchronizer` учитывает `IRunState` и 64-битный `seed`.
- Внешний обработчик исключений вокруг замены позволяет существующему коду вернуть золото при ошибке вызова, включая `MissingMethodException` во время JIT-компиляции.

В исходном журнале мод списывал 100 золота, затем падал при попытке вызвать отсутствующий `BeginEvent(Player, Boolean)`. Отдельно при инициализации не находился старый конструктор синхронизатора.

## Что проверено

Проверены все 53 прямых обращения мода к API предоставленной `sts2.dll`, используемые закрытые поля и методы перестройки события. Изменённый IL выполнен на изолированном стенде с подставными типами: передача параметров, поиск конструктора, обработка обычного исключения и настоящего JIT `MissingMethodException` прошли проверки.

**Запуск в самой игре, смена Древнего, переход в бой и мультиплеер ещё не проверены.** Патч устраняет две подтверждённые несовместимости; совместимость с другими модами не установлена. Произвольные асинхронные ошибки после запуска события или интерфейса этим патчем не обрабатываются.
