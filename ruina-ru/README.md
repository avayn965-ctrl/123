Перевод **1418 строк в 22 таблицах** Ruina 2: карты, эффекты, недуги,
зачарования, реликвии, враги, события, диалоги, намерения и обучение.

Основа — опубликованные автором исходники **Ruina 2 v1.1.5 для public-beta**,
commit `f83f90a165aa49c1ec1371b4594d8bed605c7e47`.
Загруженный пользователем `3787624064.zip` не удалось прочитать: он превышает

и контрольные суммы английских таблиц находятся в `UPSTREAM.json`.

## Установка

1. Установите исходный **Ruina 2 для public-beta** и его зависимости
   **BaseLib** и **Act Like It 2**.
2. Распакуйте папку **RuinaRussian** из архива в `Slay the Spire 2/mods`.
   Внутри должны лежать `RuinaRussian.dll` и `RuinaRussian.json`.
3. Перезапустите игру. Дополнение загружается после Ruina 2.

Оригинальный Ruina 2 из Workshop оставьте установленным. Это отдельное
дополнение: оно не содержит оригинальные DLL/PCK, музыку, изображения или файлы
игры. Для обычной установки перевод GuZhenRen не требуется.

## Клавиши и язык

- По умолчанию тексты Ruina 2 русские, независимо от языка игры.
- **P**: русский → английский → русский, только для Ruina 2.
- Используется физическая клавиша P: русская раскладка также подходит.
- Удержание клавиши срабатывает один раз. Во время ввода в текстовое поле или
  чат, а также при Ctrl/Alt/Meta+P, язык не меняется.
- Если установлен ранее выпущенный **GuZhenRenRussian**, его переключение
  переносится на **Shift+P**. Обычная P меняет только Ruina 2; языки независимы.
  Исходные файлы GuZhenRenRussian при этом не изменяются. Без RuinaRussian у
  GuZhenRenRussian снова используется обычная P.
- Выбор сохраняется локально в `user://ruina-russian-language.txt` и переживает
  перезапуск. Удаление этого файла возвращает русский язык по умолчанию.

Открытые карты обновляются с сохранением режима предпросмотра улучшений.
Слушатели изменения языка получают уведомление. Уже созданные подсказки,
реплики и отдельные описания с закэшированными именами могут обновиться после
повторного наведения или открытия соответствующего окна.

## Мультиплеер

Клавиша обрабатывается в общем цикле Godot, независимо от числа игроков,
наличия локального персонажа, роли хоста и паузы. Каждый игрок выбирает язык
самостоятельно. Дополнение объявлено `affects_gameplay: false`; оно не отправляет
сетевые сообщения, не меняет RNG, параметры карт, награды или действия игроков.

Учтено взаимодействие с реликвией GuZhenRen, считающей длину названий карт:
при её расчёте используются исходные названия Ruina 2, независимо от выбранного
языка. Это действует с установленным GuZhenRenRussian и без него.

Все игроки по-прежнему должны иметь совместимые версии **самого Ruina 2**, игры
и игровых зависимостей. Перевод не адаптирует новый Ruina 2 к старой сборке игры.

## Проверки и ограничения

- Проверены все ключи, переменные, вызовы форматтеров, условия и цветовая разметка.
- Английские строки сохранены по исходникам. Русские числовые фразы не используют
  английские формы множественного числа. Для английского режима используются
  английские правила форматирования, даже если игра запущена на китайском.
- Сборка и аудит API по ранее предоставленному `sts2.dll` версии 0.111.0.
- 27 проверок в настоящем Godot 4.5.1 с Harmony, SmartFormat и тестовыми классами
  игры: клавиши, видимые карты, чат, пауза, совместимость с GuZhenRenRussian,
  сохранение исходного расчёта реликвии и английское множественное число.
- Отдельные процессы проверяют сохранение языка после перезапуска и независимость
  настроек двух пользователей.

**Полная игра и настоящий сетевой сеанс в этой среде не запускались.** Проверки
с тестовыми классами не подтверждают совместимость с каждой версией игры или
непроверенным DLL/PCK из пользовательского архива.

## Сборка

Нужны .NET 9, Godot 4.5.1 Mono, собственный `sts2.dll`, `GodotSharp.dll`,
`0Harmony.dll` и ранее выпущенный `GuZhenRenRussian.dll` только для проверки
совместной работы. В итоговый архив эти зависимости не включаются.

```sh
python3 ruina-ru/tools/build_release.py \
  --dotnet /path/to/dotnet \
  --game-dll /path/to/sts2.dll \
  --godotsharp /path/to/GodotSharp.dll \
  --harmony /path/to/0Harmony.dll \
  --gu-addon /path/to/GuZhenRenRussian.dll \
  --godot /path/to/Godot_mono
```

Для проверки только таблиц: `python3 ruina-ru/tools/validate_translations.py`.
Тестовый проект создаёт **фиктивную сборку `sts2.dll`**; устанавливать её в игру
нельзя. Устанавливается только DLL из готового архива дополнения.
